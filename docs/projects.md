# Рецепты и проекты

Что можно сделать на станции, опираясь на разобранные механизмы. От «быстро и
полезно» к «амбициозно». Примеры снимались на
[Станции Лайт](devices/station-lite.md).

## A. Свой звук через `gst-launch`

Ключевой приём — встроенный [`maind --gst-launch`](platform/architecture.md#gst-launch):
не нужен сторонний ffmpeg/aplay, в прошивке уже есть полный GStreamer.

- **Интернет-радио / поток по кнопке:**
  ```sh
  maind --gst-launch "souphttpsrc location=<url> ! decodebin ! \
    audioconvert ! audioresample ! alsasink"
  ```
- **Своя побудка / уведомление:** проиграть локальный файл с `/data/opt`.
- **Мультирум / стерео-синхрон:** `--gst-launch --clock <host:port> ... --next ...`
  (родной синхроклок прошивки) — связать две колонки/ПК.

## B. Индикация через LED-кольцо { #led }

Формат [`.led` декодирован](devices/station-lite.md#led-format).

- **Физический нотификатор:** свои `.led`-анимации + `led_util`, или прямо
  `/sys/class/leds/...`. Привязать к статусам сборок/CI, событиям умного дома,
  уведомлениям.
- **Генератор `.led`** из палитры — единый «цветовой язык» индикации.

## C. Умный дом / хаб

- На борту уже включены **Matter** (есть PAA-сертификаты) и **Zenoh** — станция как
  готовый Matter-контроллер; рулить можно локально (glagol/mDNS), без облака.
- Zenoh (`:7447`) — лёгкая pub/sub-шина между станцией, ПК и другими устройствами.

## D. Голос / звук как сенсор

- `arecord` пишет с PDM-матрицы (+ аппаратный AEC-loopback): детектор хлопка/шума
  как триггер для сцен или подсветки; локальная запись заметок.
- SAR-сенсор (`event1`) и кнопка (`event0`) → свои хоткеи (слушать `/dev/input/event*`).

!!! warning "Приватность"
    Микрофон — осознанно, лучше по кнопке/касанию, не постоянно.

## E. Инфраструктура / always-on узел

- **cron на борту:** `crond` есть, не запущен — поднять из `S99z`-скрипта.
- **Tailscale/VPN-нода:** собрать статический `tailscaled` (aarch64/musl) → станция в
  приватной сети; subnet-router для устройств за NAT/изоляцией.
- **USB-gadget** через configfs: кроме adb добавить RNDIS-ethernet или serial —
  запасной канал управления без Wi-Fi.
- **Мониторинг:** экспорт метрик (temp/loadavg/RAM) в свой дашборд.

## F. Исследовательское (нужно для вики)

- **rh_unlock / serial-консоль:** распиновка UART, лог U-Boot, доступ к bootloader
  env; задокументировать dev-unlock.
- **Карта I2C-регистров** усилителя/LED/сенсора через `i2cdump` (аккуратно).
- **Дамп разделов** (`recovery`, `boot`, `nv`) через `/dev/mtd*` → разбор формата
  прошивки и OTA.
- **Протоколы `:5081` и Zenoh `:7447`** — что именно отвечает.
- **Новые модели:** снять базовые данные и
  [добавить в матрицу](devices/index.md#support-matrix).

## Порядок, если брать по одному

1. **Звук через `gst-launch`** — сразу слышимый результат.
2. **LED-нотификатор** — быстро и эффектно.
3. **crond + VPN-нода** — делает станцию полезным always-on узлом.
4. **Matter/Zenoh-хаб** — самое «умный дом», но дольше.
