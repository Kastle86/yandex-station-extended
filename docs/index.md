# Yandex Station Extended

**Yandex Station Extended (YSE)** — community-вики по исследованию и модификации
умных колонок Яндекса (семейство «Станций»). Цель — собрать в одном месте проверенные
знания: как получить доступ к устройству, как устроена прошивка `quasar`, какое
железо внутри разных моделей и какие модификации возможны — чтобы владельцы могли
чинить, изучать и расширять свои колонки.

!!! warning "Дисклеймер"
    Всё в этой вики — для работы со **своим** устройством (ремонт, изучение, домашняя
    автоматизация). Модификация прошивки может лишить гарантии и, при ошибке, привести
    к «кирпичу» — действуйте осознанно и с бэкапами. Персональные данные (приватные
    ключи `devices.json`, MAC, серийники, координаты) в вики не публикуются. TEE/
    keymaster и glagol-ключи не трогаем — их компрометация ломает доверие устройства
    в облаке.

## Термины

- **quasar** — прошивочный стек Яндекса (всё в бинарнике `maind`), общий для
  Amlogic-станций.
- **glagol** — локальный API колонки (управление без облака, TLS на `:1961`).
- **Станция Лайт / Micro** — одна и та же модель; в device-tree называется
  `Yandex Station Micro v1.2`, в рознице — «Станция Лайт».
