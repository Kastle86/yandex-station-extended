# Станция Мини 3 (bergamot)

Розничное имя — **Яндекс Станция Мини 3** (в модификациях с LED-часами и без них); кодовое имя — **Bergamot** (`Yandex Station Mini 3`, `yandex,station-mini3`, `amlogic, axg`).

Это третье поколение компактных Станций на платформе Amlogic. Ниже приведены проверенные на живых устройствах данные реверс-инжиниринга прошивки (ветка quasar 3.21, сборка `0.369.1.50...`).

---

## ⚡ Платформа в двух словах

| Параметр | Значение |
|---|---|
| **Кодовое имя** | `bergamot` / `yandex,station-mini3` |
| **SoC** | **Amlogic AXG (A113-семейство)** |
| **CPU** | 4× ARM Cortex-A53, до **1.2 ГГц** |
| **ОЗУ** | **~244 МБ** (доступно свободно ~130 МБ в штатном режиме) |
| **Флеш** | **NAND SLC 256 МБ**, разметка UBI поверх MTD |
| **Ядро** | Linux **4.9.68 aarch64** (64-бит) |
| **Userspace** | **32-бит armhf**, glibc 2.30, Buildroot |
| **Сетевые интерфейсы** | Wi-Fi 2.4 / 5 ГГц + Bluetooth (SDIO) |
| **Индикация** | 6 RGB-зон кольца через `/dev/fb0` + белые сегменты часов |
| **Аудиовыход** | Встроенный широкополосный динамик + AUX 3.5 мм |
| **Порт питания** | USB Type-C (5V / 9V) |

!!! note "Разрядность ядра и приложений"
    Как и на Станциях Лайт и Мини 2, ядро Linux здесь **64-битное (`aarch64`)**, а пользовательские процессы Quasar скомпилированы под **32-битный `armhf`**. Любой сторонний софт рекомендуется собирать статикой под `aarch64-linux-musl` (см. [Сборка софта](../platform/toolchain.md)).

## 🌈 Уникальная система подсветки: Framebuffer `/dev/fb0`

В отличие от Станции Лайт и Мини 2, где светодиодами можно управлять через стандартный интерфейс ядра `/sys/class/leds/`, в **Мини 3 кольцо управляется напрямую через фреймбуфер**!

### Кольцевая подсветка (6 RGB-зон):
* Устройство: **`/dev/fb0`** (виртуальный дисплей размером 6×1 пикселей).
* Формат цвета: **24 бита на пиксель (BGR)** — синий, зелёный, красный (по 1 байту на цвет).
* Размер буфера: ровно **18 байт** (6 зон × 3 байта).

#### Прямое управление цветом из консоли:
```sh
# Залить все 6 зон синим цветом (B=40, G=00, R=00):
printf '\100\000\000\100\000\000\100\000\000\100\000\000\100\000\000\100\000\000' > /dev/fb0

# Залить все 6 зон фиолетовым цветом Алисы (#7A55FF -> B=FF, G=55, R=7A):
printf '\377\125\172\377\125\172\377\125\172\377\125\172\377\125\172\377\125\172' > /dev/fb0

# Погасить всё кольцо:
dd if=/dev/zero of=/dev/fb0 bs=18 count=1 2>/dev/null
```

Классы в `/sys/class/leds/bergamot:{red,green,blue}:logoN` имеют триггер `ledfb-logo` и лишь пассивно отражают состояние буфера `/dev/fb0`.

#### Системные анимации:
Штатные световые паттерны хранятся в каталоге `/system/vendor/quasar/ledpatterns/oknix/*.led`.  
Воспроизвести любой системный эффект можно утилитой:
```sh
led_util /system/vendor/quasar/ledpatterns/oknix/listening.led
```

## ⏰ LED-часы (в моделях с дисплеем)

В модификации с часами за вывод времени, температуры и анимаций («глазки», смайлики) отвечает драйвер `clock_led_util` (симлинк на `maind`).

* Сегменты циферблата адресуются через специализированный контроллер матрицы.
* Для рисования собственных пиксельных иконок и анимаций используется скрипт `smiley_editor.py` из каталога `contrib/`.

## 🗺️ Внутренние IPC-порты сервисов Quasar

В прошивке Мини 3 процессы общаются между собой по локальному TCP-стеку через `127.0.0.1`:

| Порт | Сервис / Модуль | Описание |
|---|---|---|
| **`9875`** | `aliced` | Диалоговый движок Алисы и локальный стейт |
| **`9891`** | `external_commandsd` | Демон внешних системных команд |
| **`9899`** | `glagold` | Локальный шлюз Glagol |
| **`9900`** | `mediad` | Контроллер воспроизведения музыки и GStreamer |
| **`9906`** | `audioclient` | Клиент аудиотракта и микширования |
| **`9910`** | `iohub_clients` | Клиентская шина умного дома |
| **`9922`** | `volume_manager` | Менеджер аппаратной громкости |

## 🔓 Разблокировка и Root

На Станции Мини 3 работает универсальный метод перехвата обновления через DNS `179.254.167.126` (см. [Полный гайд разблокировки](../platform/access.md#dns-unlock)).

После первого входа по `adb connect <IP>:5555`:
1. Перемонтируйте файловую систему: `mount -o remount,rw /`
2. Отключите `updatesd` в `/etc/launch.json`.
3. Зафиксируйте флаги автозапуска ADB в `/data/quasar/` через `chattr +i`.
