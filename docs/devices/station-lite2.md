# Станция Лайт 2 (plum)

Розничное имя — **Яндекс Станция Лайт 2**; кодовое имя платформы — **Plum** (`yandex,station-lite2` / `amlogic, axg`).

Второе поколение популярной компактной колонки. Участники сообщества разобрали устройство и исследовали его прошивку.

---

## Платформа и аппаратная часть

В отличие от Станции Стрит (где Яндекс перешёл на дешёвый 32-битный чип Amlogic A1), в **Станции Лайт 2 производитель вернулся к проверенному семейству Amlogic AXG (A113X)**!

| Параметр | Значение |
|---|---|
| **Кодовое имя** | `plum` |
| **SoC** | **Amlogic AXG (A113X)**, `amlogic, axg` |
| **Архитектура CPU** | 4× ARM Cortex-A53, до **1.2 ГГц** |
| **Ядро** | Linux **4.9.68 aarch64** (64-бит) |
| **Userspace** | **32-бит armhf**, Buildroot, glibc 2.30 |
| **Память** | 256 МБ NAND SLC, UBI поверх MTD |
| **Прошивка** | Quasar 3.21 (нативный монолит `maind`) |
| **Беспроводная связь** | Wi-Fi 2.4 / 5 ГГц + Bluetooth (комбо-чип Unisoc) |
| **Питание** | USB Type-C (5V) |

---

## Ключевые отличия от Лайт 1-го поколения

1. **Кодовое имя прошивки:**
   * У Лайт 1: `yandexmicro` / `micro`.
   * У Лайт 2: **`plum`**.
2. **Звуковой тракт и динамик:**
   * Мощность звука увеличена до 6 Вт (в первой версии было 5 Вт).
   * Новый компактный широкополосный излучатель и переработанная акустическая камера.
3. **LED-индикация:**
   * Световые анимации переработаны, сохранено кольцевое расположение светодиодов в верхней части корпуса.
4. **Уязвимость протокола загрузки:**
   * Так как на борту установлен классический процессор Amlogic A113X, на устройстве присутствует штатный сервисный протокол **Amlogic USB Download Mode** (через Amlogic USB Burning Tool).

## Разблокировка и Root

Станция Лайт 2 (`plum`) полностью уязвима к стандартному перехвату обновлений через DNS `179.254.167.126`:

1. Сброс до заводских настроек.
2. Включение DNS на этапе выбора Wi-Fi в приложении Яндекса.
3. Получение даунгрейда прошивки с открытым портом `5555`.
4. Подключение:
   ```sh
   adb connect <IP_колонки>:5555
   adb shell
   ```
5. Закрепление доступа и отключение OTA по инструкции из раздела [Получение доступа](../start/ssh.md#kill-ota).
